# Fitchat 手机端走查清单（演示版）

> 这份清单是给「人」照着做的，不是给自动化测试跑的。测试只能验证逻辑，验证不了布局——文字溢出、标签碰撞、点击区域过小，只有实际渲染出来看才会发现。
>
> 请用手机尺寸实际点一遍。发现问题就按 **页面 / 现象 / 复现步骤 / 期望行为** 记下来，先别急着改。

## 一、怎么打开

项目就是这个仓库本身（`C:\Users\admin\codex_project\Fitchat`）。在终端进入该目录并启动：

```bash
cd C:\Users\admin\codex_project\Fitchat
npm run dev
```

等它打印出地址后，在浏览器打开 `http://localhost:3000`。

- 依赖已经装好了（`node_modules` 就在这个目录里）。如果哪天提示找不到依赖，先跑一次 `npm install`。
- 如果它提示端口被占用（"port 3000 is already in use"），说明已经有一个在跑了，直接打开 `http://localhost:3000` 即可，不用重复启动。
- 浏览器里模拟手机：按 `F12` 打开开发者工具，点左上角「手机/平板」图标（Toggle device toolbar），把尺寸设为 iPhone 尺寸（390×844，或直接选一个 iPhone 机型）。
- 用真手机看（推荐，这是手机优先的产品）：让手机和电脑连同一个 Wi-Fi，启动 `npm run dev -- --hostname 0.0.0.0`，在电脑上运行 `ipconfig`，找到「无线局域网适配器 WLAN」里的 IPv4 地址（形如 `192.168.x.x`），在手机浏览器打开 `http://<那个IP>:3000`。注意：这会把服务暴露给同一局域网内的其他设备，用完记得停掉服务。

### 全站通用（每个页面都看一遍）

| # | 看什么 | 通过标准 | 什么算坏了 |

## 三、演示数据里容易误判的几个状态（实测，不是推测）

以下是**实际跑出来的数字**，看清它们能避免把正常数据当成 bug：

**今天（2026-09-22）恰好是休息日。** 实测今天运动为 **0 / 500**，所以运动环是空的、首页「今日运动」显示空态，**净热量等于摄入 1563**。而训练计划显示周二「胸 + 三头」——**这是有意保留的**：记录反映的是实际发生的事，不是计划的事，用户跳过当天的训练是真实场景。想看有运动的一天，用日历页点开任意一天即可。

**「圆环恰好满环」是可达的**，与旧版清单的说法相反。实测：

- **2025-09-24** 与 **2025-10-22**：热量恰好 1800（满环）
- **2026-02-23**：运动恰好 500（满环）

这三天的圆环会画成完整一圈，圆头线帽在 12 点方向重叠，可能凸出一个小点——**请按 D4 专门看一眼**。

**「超出」标记也是可达的**：366 天里有 **105 天**摄入超标（例：**2025-09-30**、2025-10-04、2025-10-06），点开这些日期就能看到图例里的「超出」。

**其余量级参考**（用来判断界面上的数字是否离谱）：

- 摄入盈余范围：**−471 ~ +447** 千卡，未超标 261 天 / 超标 105 天
- 无运动的天数：**95 / 366**（约四分之一）
- 体重序列：从 **2025-09-22 的 77.9kg** 降到 **今天的 69.2kg**，目标 65kg

## 四、已知限制：demo 与真实产品的差距

务必读一遍，别把演示当成品：

- **所有数据都是按日期生成的**：不是写死的常量，但也不来自真实记录，更不落库、不持久化，刷新就回到原样。
- **没有登录与权限**：登录页只是界面，任何页面都可以直接打开，没有真正的注册、邀请码校验或会话。
- **「保存」「解析」没有真实副作用**：解析返回的是预设的假结果，保存不会真的写入任何东西。
- **没有接入 AI**：界面上的「AI 估算」标签来自生成规则，没有接 DeepSeek 或任何大模型。
- **目标热量是写死的数字**：1800 千卡等目标是写死的，没有实现真实的目标计算。
- **没有错误监控**：没有接入任何日志、监控或崩溃上报。
- **「今天」是写死的 2026-09-22**：演示把「今天」固定在这一天（含星期），首页、日历高亮、训练计划的「今天」都以它为准，不是真实的系统日期。首页的日期栏文案也是写死的。
- **训练计划与运动记录互不相关**：计划是固定的周表，运动记录由生成规则独立产生，两者不会对齐——这是刻意的，因为记录反映的是实际发生的事。
- **记录的起点是「用户开始使用日期」**（演示里为 2025-09-22），该日期之前的日期没有数据；界面对「还没开始使用」与「当天没有活动」是区别对待的。
