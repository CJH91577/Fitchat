# Fitchat

移动优先的 H5 饮食与健身前端演示，基于 Next.js + React + TypeScript，数据全部来自本地 mock（无后端）。

## 运行

本项目唯一使用 npm 作为包管理器：

```bash
npm install
npm run dev     # 启动开发服务器 http://localhost:3000
npm test        # 运行全部测试
npm run lint    # ESLint 检查
npm run build   # 生产构建
```

## 说明

- 移动优先的单页演示，所有数据为本地 mock。
- 字体统一使用系统无衬线字体栈。
